# Framework policies — index

This folder holds the **framework's own** policy documents. They are published by the framework and replaced
wholesale on every `gov upgrade`, so an edit made here is lost without a merge conflict to warn you. Your
organization's governance lives in `policies/`, which gov seeds once and never overwrites.

## In this folder

- [Framework Policy](framework-policy.md) — the framework's governance instrument. Notation and compliance
  levels (§1–§2) · the Policy Owner and how approval is enforced (§3) · units of work (§4) · GitHub (§5) ·
  GitHub Projects (§6) · workspace and boundaries (§7) · knowledge management (§8) · agent operating standards,
  including credentials and data handling (§9) · compliance and enforcement (§10) · the exception process (§11).
- `.pol-lock.json` — generated by `gov rules build`. The append-only map from clause to POL number. Never
  reorder, renumber or hand-edit it.

## Why this file states no rules

It is navigation. `gov rules build` reporting **0 clauses** here is the correct answer, not a gap.

Every rule this page could state is already stated where it belongs: that the folder is the framework's and not
yours is `framework-policy.md` §10.1, and the banner at the top of that document. Restating either here would
create a second copy of a fact, free to drift from the first, in a file nobody re-reads — which is what
`policies/knowledge-organization-standard.md` §1 (GOV-FRM-402) exists to prevent. An index that numbered its own
bullets so they could compile to rules would be governing the act of listing files.
