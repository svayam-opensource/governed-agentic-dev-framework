# Projects

This folder contains all project workspaces for <ORG_NAME> agentic development projects.

Each subfolder corresponds to one project, named `PRJ-<board#>-<slug>`.
Project workspaces are created by `gov seed` and live on project branches (`BRNCH-<board#>-<slug>`).

Projects are tracked on GitHub (Project boards + anchor issues) — there is no `registry.yaml`.
See `framework/docs/specs/framework-specification.md` for how the framework works, and `policies/` for your organization's rules.
