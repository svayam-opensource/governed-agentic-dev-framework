Install gov in one command.

gov installs its own private Node and leaves the one you already have alone. No administrator rights, no package manager, nothing to uninstall but one directory.

serving {{REF}} installs {{PKG}} host {{HOST}}
curl -fsSL https://{{HOST}}/install.sh -o install.sh && bash install.sh

In Terminal. Reads the plan to you and asks before it installs anything; when it finishes, gov starts the first-run flow below. View install.sh.

Fetch, then run: piped straight into bash, a failed download exits 0 and installs nothing without saying so. In CI, where the exit status is checked, curl -fsSL https://{{HOST}}/install.sh | GOV_YES=1 bash also works.

curl -fsSL https://{{HOST}}/install.sh -o install.sh && bash install.sh

The same installer as macOS. It needs only curl and tar, asks before it installs anything, and then gov starts the first-run flow below. Set GOV_YES=1 to skip the prompt in a script. View install.sh.

winget install Svayam.Gov

Or download the signed .msi for your machine (x64 or arm64) from the release page and run it. Either way gov installs for you alone — no administrator rights, its own Node, gov on your PATH — and the installer's last page offers Launch gov, which starts the first-run flow below.

Not live yet: the Windows door opens with the first signed release. Until then winget will not find Svayam.Gov and the release page has no .msi, so there is no Windows door yet.

Then: the first-run flow — the same on every OS

  1. gov checks git and gh, installs what is missing if you agree, and asks you to sign in to GitHub. Re-running resumes; it never repeats a finished step.
  2. It asks: are you adopting the framework for your organization, joining one that already has it, or not sure? Not sure explains the difference and changes nothing.
  3. Adopt creates and seeds your governance repo; join finds it on GitHub and clones it.
  4. gov installs an approved AI agent, if you agree, and helps you sign it in.
  5. It opens a first project and launches the agent, which posts its context manifest. That is the end of setup.

What it does to this machine

  • macOS and Linux: a private Node under ~/.local/share/gov, and gov linked into ~/.local/bin. If that folder is not on your PATH, one marked line is appended to your shell profile, and the installer names the file.
  • Windows: one per-user program (%LOCALAPPDATA%\Programs\gov), removable from Settings → Apps; your ~/.gov stays.
  • Installs git or gh only if they are missing — and asks first.

What it needs from you

  • A GitHub account with access to your organization.
  • A sign-in only a person can do — gov never stores a credential for you.
  • Nothing else. Re-running is boring by design: it resumes, it does not repeat.
