This file is the project's **carry-forward** list. Project goals live on

## How this is used

- **At session start**, the agent reads this file as part of project
  context (POL-079). Open items here should be surfaced to the developer
  before new work is planned.
- **During work**, the agent (or developer) appends new items to
  `## Open` as they arise. Don't wait until session end — the value of
  a carry-forward list is in catching things as they happen.
- **When an item is done**, move it from `## Open` to `## Done` with a
  short note (commit SHA, PR link, or one-line outcome).
- **When the user switches branch** to a different project, this file
  stays here on this project's branch; the new project's branch has
  its own. Projects are stateful; sessions are not.
